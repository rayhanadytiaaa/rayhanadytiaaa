# About Me
Hi there! I'm an IT professional with a strong foundation in web development, UI/UX design, and software quality assurance. Currently, I'm focused on optimizing web applications and sharpening my expertise in software testing and modern frontend technologies. I have hands-on experience building projects like the Dunkers e-commerce platform featuring a collaborative filtering recommendation engine, as well as handling UI/UX design initiatives for the West Sumatra Education Office. Outside of coding, I enjoy bridging the gap between smoothly building a system and meticulously breaking it down to ensure top-notch quality.
